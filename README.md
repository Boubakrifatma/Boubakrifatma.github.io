# Fatma Boubakri — Portfolio

Personal portfolio: Cloud & DevOps engineering student at ESPRIT.

Live: https://boubakrifatma.github.io

## Deployment

Every push to `main` runs a GitHub Actions workflow (`.github/workflows/deploy.yml`)
that checks the site and deploys it to GitHub Pages.

```
git push  ->  GitHub Actions  ->  GitHub Pages (HTTPS)
```
